# F-22 猛禽 · Three.js 三维模型

[打开交互式模型](https://enzoqie.github.io/f22-raptor-3d/)

使用 Three.js 从零程序化构建的 F-22 外观模型。几何、材质和 Three.js 均包含在单个 `index.html` 文件中，也可以下载后离线打开。

## 操作

- 拖动旋转，滚轮缩放，右键拖动平移。
- 手机单指旋转，双指缩放和平移。
- 底部切换透视、俯视、正视、侧视、后视和仰视。
- 右上角切换实体与线框，按 R 复位。

需要支持 WebGL 的浏览器。局部曲面根据公开照片和三视图近似重建。
